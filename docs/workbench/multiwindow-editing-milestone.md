# M2.m 可编辑多窗口、稳定性验收与日常使用说明

日期：2026-10-16。本地基线 `2f664907b`；公开开发分支仍为 `231f3aa4ba2b337e1a6a9f46cd8493b397fb1722`。本阶段仅本地提交，不推送、不改main。完整原92目标继续保留，M2.m不代表应用整体完成。

## 行为与实现

固定会话副窗口默认只读，明确取得编辑权后才核验并开放输入。主进程按窗口、会话、随机租约和确认版本校验每次草稿写入；同会话必须先保存释放再转移，过期写入拒绝，不抢占。不同会话各自保稿；统一执行门一次只允许一个确认/生成。同会话观察窗口共享正文/生成/停止，确认只属于发起者。归档、归档结果未知及临时来源保持只读；搜索来源需先核验持久ID。

副运行时借用唯一受控核心，不能释放/重连核心或改主窗口lastId/freshDraft；未持有租约的旧运行时不能回写旧草稿。工作台单实例只约束自己的窗口，主生成时沿用主路由导航限制，其他会话仍可编辑。

关闭桥绑定确切sender/frame/URL、随机nonce及会话/版本/租约/文字证明，先flush所有相关界面再等待存储确认；保存失败、超时或组合输入未完成时保留窗口与本地文字。主关闭准备失败不拆除任何窗口绑定；关闭生成副窗保留后台运行时与执行门到终态，再释放订阅。已确认关闭不增加一次多余的失败写入。

发送前先持久保存本次token、线程、原文与最新保存轮次边界，失败则不调用turn/start。ACK后立即在同一原子事务清空匹配已发送草稿及未决记录。未知结果跨重启锁全局发送及源会话编辑；保存失败保留磁盘确认版。明确只读核对需要同一官方持久线程、当前连接代次、无执行中轮次、边界之后原文正向匹配；只读最近20个完整轮次，证据不足继续锁定且不自动重发。其他新草稿保留。重试保存不能解开未知执行门，断连过渡也不能提前释放。

## 使用与边界

按[日常使用说明](daily-use.md)启动和恢复；[实施方案](multiwindow-editing-plan.md)保留归属/互斥/关闭与验收设计。工作台本地sessions.json旧版兼容，无效/未来/不安全文件不覆盖。

未决核对不把“未找到”当作“未发送”，没有强制解锁入口。边界超出最近20轮或无法取得正向证据会继续锁定；其他客户端发送完全相同文字时不能证明请求归属。官方协议没有跨客户端CAS、跨页快照或本工作台请求幂等键，不能承诺并发外部修改及硬件断电下的完整一致性。
