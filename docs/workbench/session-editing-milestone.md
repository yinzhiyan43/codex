## 可用流程

- 已读取的保存记录在终态轮次文字后显示“从此轮分叉”。确认说明包含所选轮次及之前上下文，排除其后轮次；取消不发请求。完整会话分叉入口保留。正文刷新后才能为新增实时轮次提供已保存边界。
- 官方分区对话框可按 ID 重命名所选分区。请求只发 `sectionId/name`，省略 `appearance`，保留原外观；本地已登记会话的同 ID 名称镜像一并更新。
- 分区对话框可刷新官方顺序，选择放在同分区的某会话之前，或放到末尾。移动后重新读元数据与完整有界顺序，验证成员及相邻关系，再单事务保存镜像。侧栏在本地置顶优先的前提下使用已核实的分区顺序；对话框显示官方返回顺序。
- 右键“重命名整个本地项目”在确认后修改所有同标签记录，包含已归档记录。与已有其他标签同名则拒绝，避免隐式合并；失败写入完整回滚，正文、草稿和 cwd 保持原值。

项目仍是明确标注的工作台本地标签，不调用实验 `project/*` 或 `thread/list.projectId`。分区重命名、读取与排序走固定核心的标准接口。删除、分享、外观编辑、官方项目管理及未知参考子菜单均未接入。

## 边界、并发和持久化

`thread/fork.lastTurnId` 是包含式边界；实验性 `beforeTurnId` 仍被拒绝。目标必须属于当前选中来源的完整已保存轮次缓存、非 stale、非进行中，并在创建前以同代次的服务器完整轮次页重新核对。它不接受 renderer 自造的任意轮次或另一个来源的 ID。核心仍有最终判断权：部分 legacy 存档可展示合成终态轮次，却没有可分叉的原始 TurnStarted；被核心拒绝时保留源，不制造成功结果。

沿用 M2.d 的分叉未知结果持久标记、容量预留、严格 child/parent 响应身份、ACK 后登记和取消自动打开语义。历史入口同样可取消；管理进行中禁止切换来源，防止迟到结果改变新的选择。重复确认在界面消费一次，host 仍拒绝并发创建。

分区顺序使用 `sectionId + section_position ASC`，显式覆盖固定协议全部 10 种来源，避免隐藏 Exec/SubAgent 成员影响锚点。只在完整扫描不超过 200 条/16 页后开放锚点；恰达 200 且还有游标即停止，不请求超额页。重复成员、游标循环、错误成员、失效锚点或相邻性变化均拒绝整次顺序导入，禁用锚点并要求刷新。

分区分页没有服务器快照，外部客户端并发改序不能保证原子观察。本轮会拒绝检测到的重复/相邻性冲突，不声称覆盖不可检测的分页间变化。远端移动 ACK 不等于本地成功；后续验证失败保留本地原归属，远端可能已变，需要显式刷新或重新打开。没有自动重试或假称远端回滚。

`sessions.json` version 1 增加可选 `sectionPosition` 展示镜像，写前和加载时限制为 0–199；旧文件可读。沿用私有原子文件写入与串行事务。不承诺将新增元数据降级到更旧工作台代码后完整保留。其余正文、目录、帧和记录上限不变。
