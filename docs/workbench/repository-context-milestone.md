# M3.a 仓库上下文与只读文件/Git检查

日期：2026-10-17。基线为本地 `256db6173e0ec55138b13cf8b95828dce4e7cedc`，开发分支 `workbench/desktop-stable-0.162.1`。本轮仅本地提交，无push；原92个目标及未完成范围保留。具体退出条件见[方案](repository-context-plan.md)，操作见[日常说明](daily-use.md)，脱敏验证见[机器结果](repository-context-results.json)。

## 结果

主窗口及固定会话副窗口新增原生文件夹选择、有界目录/UTF-8文字与Git状态/差异面板。新草稿可显式替换根并保留文字，已有会话只允许绑定与其官方cwd一致的目录。持久记录保存cwd基线及路径/设备/inode授权，之后cwd变化、同路径目录被替换或根失效均拒绝静默采用；恢复原目录或建立新会话。新线程使用所选cwd，分叉核对并继承来源授权，start/resume/fork回执也核对cwd。

同会话各窗口共享授权，文件/目录/补丁展示各自独立。命令绑定真实sender、会话、随机scope与查询序列；旧命令/响应失效，UI只接纳非过期版本。重启保留授权与草稿，不自动读取文件或恢复副窗。关闭先取消并等待原生读取退出；根失效会清除旧文件及Git补丁。浏览内容用textContent展示，不自动附加模型输入；原有文本聊天、read-only及禁止网络策略保持。

## 读取边界与接口选择

官方固定版本的[fs协议](../../codex-rs/app-server-protocol/src/protocol/v2/fs.rs)采用绝对路径，当前[fs处理器](../../codex-rs/app-server/src/request_processors/fs_processor.rs)将sandbox传为None，[本地整文件读取](../../codex-rs/exec-server/src/local_file_system_read.rs)上限512 MiB，不符合本阶段根授权/小预览限制。因此没有把这些RPC直接开放给renderer，采用明确标注的本地只读代理；官方线程元数据仍是cwd事实来源。官方project实验接口尚未接入，[项目处理器](../../codex-rs/app-server/src/request_processors/projects.rs)对无SQLite状态返回不可用。本地标签、文件夹授权均不冒充官方项目管理。

文件助手逐段openat/O_NOFOLLOW，核对根设备/inode，阻止绝对/父路径、链接、特殊文件及.git内部路径；单目录200项、不递归，文本256 KiB、严格UTF-8/二进制判定，读取前后核对变化。父目录并发换成根外链接的合成攻击也未读到另一根内容。

Git使用构建时固定的系统Git，不经过shell，不接受任意参数或环境。只开放status及选定条目的已暂存/未暂存diff；关闭外部diff/textconv、fsmonitor、hooks、子模块递归与可选写锁。macOS沙箱禁止网络、普通文件写入和其他程序执行，文件内容读取限根及必要系统运行库。`/dev/null`是唯一写例外；`(literal "/")`只许可根目录自身，不能改为`(subpath "/")`。沙箱不可用则禁用Git，不降级执行。linked worktree/submodule的.git文件、.git链接、外部元数据及非仓库不开放。根外config include读取被拒绝，恶意外部程序夹具未执行，索引字节保持。

每个助手最长4秒、单进程输出512 KiB，全局最多4个在途进程；超时/超量终止并报错，不把不完整内容假装完整。二进制Git补丁保持文字说明，超大补丁不预览。构建依赖本机Xcode命令行工具；本轮未安装软件或新增依赖。
