## 官方接口与真实范围

官方源码与隔离原生调用均确认 `thread/search` 是可用的实验接口，需要 initialize 的 `experimentalApi:true`。它通过官方存储搜索保存记录文件（包括官方支持的压缩记录），从用户/助手文字中提取忽略大小写的字面匹配片段，返回会话元数据、snippet、nextCursor。不是工作台私读历史、自建正文索引或发送模型请求。实现见 `codex-rs/thread-store/src/local/search_threads.rs`、`codex-rs/rollout/src/search.rs` 和 `codex-rs/app-server/src/request_processors/thread_processor.rs`。

稳定 `thread/list.searchTerm` 对名称、提取标题和 preview 元数据作子串筛选，因此界面明确称“标题/预览”，不承诺正文命中。两种模式都由官方核心查询，能找到不在当前已加载侧栏中的历史。归档条件 false/true 分别查询未归档/已归档；没有把两者混成一页。默认不传 sourceKinds，遵循官方交互来源 cli/vscode/custom atlas/chatgpt，避免显式枚举遗漏官方 Custom 来源。Exec、MCP、子代理等非默认交互来源未纳入本轮。

正文依赖官方记录文件，不承诺未保存的实时文字、仅数据库中的历史、工具结果或附件命中。官方 API 不返回精确轮次/条目锚点；结果打开会话只读副窗，再通过已有完整轮次分页读取保存正文，不声称直接跳到命中行。`thread/searchOccurrences` 等其他实验接口仍关闭。核心可能在后续版本改变实验协议，升级必须重新导出、核验并回归。

## 代码与交互

保留现有“已加载分组/标题筛选”。侧栏新增“搜索全部保存会话”和 Cmd/Ctrl+Shift+F 入口；对话框包含关键词、正文/标题预览、归档范围、搜索、取消和加载更多。显式 Enter/搜索触发官方读取；关键词或范围修改、关闭、Escape 立即使旧结果失效。空结果和失败显示可执行恢复提示。对话框有标签、状态播报、返回焦点，900px 及宽屏截图已检查。

独立 SessionSearch 只缓存本次查询的展示字段，不写 SessionStore、UI 偏好或共享 Codex 配置。每页20条，最多100条/16页，关键词128字符，游标沿用4096字符和协议帧上限。重叠结果按ID去重；重复/过期游标或失败保留旧展示但禁止打开与继续加载，需重新搜索。达到上限在发送多余页前停止。

每次连接最多一个物理搜索请求，另保留一个可替换的最新待查意图；连续关键词跳过中间意图。取消不声称终止官方文件扫描，只失效本地结果；底层返回后才继续最新查询。查询意图与核心代次共同阻止迟到响应覆盖新结果。断线/重连不自动重查；关闭工作台销毁观察者并由唯一 host 停止核心。

主进程只允许打开当前未失效结果中的ID，通过现有只读副窗路径创建或复用窗口，仍最多四扇。打开前保存防抖草稿，不替换主窗路由、会话目录、模型、待发送状态或历史分页；归档结果也只能只读查看。副窗没有搜索、写入、发送或配置桥接权限。不存在结果到任意路径/URL或任意 RPC 的转换。

协议层默认不启用搜索能力；只在聊天主 host 显式开启握手 capability，客户端精确允许 `thread/search`。原51份稳定 schema 保留，另固定两份官方0.162.1二进制在隔离、无登录、禁网环境导出的实验 schema。生成命令、源提交、二进制与 schema SHA256 写入 spec/manifest，sync/check 校验哈希；不修改上游 schema 或源码。

启用 experimentalApi 也可能使官方发送额外实验通知/命令审批字段：未知通知仍忽略，未审核的权限字段仍拒绝并断开。聊天路径继续固定工具禁用、approvalPolicy never 和只读约束。本轮未发送真实模型请求，因此不能声称真实模型回合的实验性审批兼容已验收。
