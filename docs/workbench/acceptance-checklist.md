# 功能验收清单

日期：2026-10-14；核心 `0.162.1`，UI 参考 `26.1007.30912 / 20156`。**所有工作台目标当前均未完整通过验收。** [M1.a](protocol-milestone.md)、[M1.b](transport-milestone.md)、[M1.c](desktop-milestone.md) 、[M1.d](pagination-milestone.md) 提供部分协议/host/界面合成证据；[M1.e](core-connection-milestone.md) 提供真实进程、原生账户及一次GPT文本冒烟的部分证据；用户主动提供的11张截图提供部分可见状态证据。这些均不能代替完整功能验收。

来源编号见 [参考记录](reference-observations.md)。本表覆盖目前已识别的全部目标，原有92项完整保留；在 V-01 至 V-11 全部补齐前，不能声明已穷尽闭源应用功能。新发现功能追加新 ID，不复用或删除旧 ID。

承接类型：`R` 官方普通协议/核心复用；`E` 官方实验接口；`H` 桌面 host/UI 待实现；`U` 尚无已验证的完整公开接口；`V` 需选定版本视觉证据。组合表示需要同时完成。阶段见 [实施计划](implementation-plan.md)。状态含义：待实现、待视觉、待接口核验、待范围确认、后置；均不是“通过”。

每条通过时追加验收记录：`ID / 核心SHA / UI版本 / OS / 前置条件与合成数据 / 操作步骤 / 期望与实际 / 日志或截图位置 / 日期 / 结论`。失败附复现步骤；未知接口附证据缺口。公共仓库只保存合成测试材料，不保存私人会话、登录态或凭证。跨产品功能即使后置或待决，也保留记录。
