## 目标与完成标准

在官方 fork 内开发 Mac 本地工作台，复用官方 CLI、app-server 和 Harness。布局、交互及功能以用户选定的桌面版本为参考；官方核心升级后，通过协议适配与 UI 调整跟进。插件扩展和创作能力安排在核心工作台之后，仍保留在总清单中。

完整目标不能用“能发消息”“三个面板已画好”或“一个演示流程通过”代替。完成需要：目标界面证据闭合、全部约定功能逐项验收、错误与恢复路径通过、官方核心无产品定制修改、升级回归通过。接口未知、服务不可用或视觉参考缺失的项目不能标记为通过。

规划阶段只新增本目录文档。随后经授权新增独立 `workbench/` 协议模块、stdio host 与隔离开发依赖，只运行合成契约、单元及 Node peer 测试；没有发送模型任务、读取凭证、修改官方核心或提取闭源应用代码。
