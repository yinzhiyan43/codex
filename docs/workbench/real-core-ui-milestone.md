# M2.i 真实官方核心与桌面组合验收

日期：2026-10-16。验收产品基线为已推送的 `a688598b6b46dad95f09e4f9de55dd57fc8fdf37`，分支 `workbench/desktop-stable-0.162.1`，官方核心固定 `rust-v0.162.1`。用户授权少量真实模型请求，本轮最终累计 **5 次**，终态为 4 次 `completed`、1 次 `interrupted`。没有发现需要修改产品代码的阻断性回归；本轮只提交脱敏验收文档，不推送，不改 main。

## 请求来源与设置

先使用官方 CLI 和核心的只读配置、账户及目录接口确认：固定二进制版本匹配；现有 ChatGPT 登录可用；请求使用 `openai` 提供方与官方 `https://chatgpt.com/backend-api/codex` 路由。账户类型须为 ChatGPT，禁止 API-key 回退、第三方服务、新登录或新增权限；使用现有套餐/额度。本轮没有独立金额账单或价格测量，不报告金额。

每次确认发送前核对有效配置和同一现有账户。报告只记核对结果，不保留邮箱、套餐、账户 ID、凭据或账户指纹。选用既有配置中的模型；如果未显式配置才使用已确认的目录默认值。模型、推理强度及服务层级与只读基线比较一致，出站请求不允许增加 effort/reasoning/serviceTier 字段；没有为降低测试消耗而覆盖用户设置。共享配置文件在运行前后字节哈希一致。

## 测试实例与隔离边界

实际使用生产控制器、协议适配、renderer、preload 和只读副窗。测试驱动从固定生产 main 源码派生入口，只替换独立 profile、隐藏启动、受控回调、审计与进程封装；生产 main 源文件、模型逻辑及默认用户数据目录均未修改。派生入口与测试驱动仅保存在本地测试产物及私有证据区，不纳入提交，不是新增产品功能，也不是默认用户 profile/单实例锁的验收。

本轮使用独立 CODEX_HOME、SQLite、工作台状态和空执行目录，只创建两个合成测试会话。现有登录/配置以符号链接引用，没有复制凭据内容。正式核心子进程对原 Codex 目录拒写，并拒读原 sessions/archived_sessions 正文；加固版同时拒写测试目录中的 auth/config 引用路径，保护 spawn 与 execFile，并限制 Keychain 服务访问。Electron 保持原 sandbox/contextIsolation，没有关闭浏览器沙箱来绕过启动冲突。只用自建合成 canary 验证目标目录拒写及别名 touch/truncate 拒绝，未尝试写真实凭据或配置。

**预检限制：**最早的配置/账户/目录只读预检使用了原 CODEX_HOME，且不属于后来新增的进程沙箱。官方核心启动可能扫描过既有会话目录元数据；没有请求私人会话正文，也没有将旧会话内容或元数据用作样例/写入报告。不能把该步骤追称为完全隔离，也不能仅凭文件规则宣称所有凭据后端在所有早期步骤均绝对不变。后续文件保护、合成 canary 和现有账户匹配是各自独立的证据。

## 测试驱动的失败与恢复

这不是一次无失败的端到端运行。首次外层 macOS sandbox 与 Electron 子沙箱冲突，模型请求为 0；改为只封装本轮核心子进程。首次 A 已完成后，驱动误在实时窗口查找仅保存记录提供的分叉轮次；改为刷新已保存记录并复用该会话，没有重发 A。恢复断言也改为定位已保存 A，而非把最近一条回复当成 A。

计划最初为 4 次请求；短列表在点击前已完成，故停止检查增加一次即时点击的请求，总硬上限改为 5。此后没有模型重试，也未重新创建分叉。

重启阶段已通过正文/草稿恢复、无自动发送、同 ID B 续聊与前缀保持断言，随后读取**测试驱动自己的请求账本**时遇到半截 JSON，阶段结果仍为 `failed`，没有该阶段关闭账本文件。驱动账本改为原子写入/rename；分叉已 ACK 并登记，因此后续使用 `--resume-fork-only` 打开既有子 ID，完成余下检查，不再次分叉。最终该独立恢复阶段为 `passed`；不能据此将原重启脚本整体追称通过。

这些调整均限于本地测试驱动。产品 SessionStore、偏好存储和协议代码没有本轮修复或改写。沿用已推送产品基线的 237 项离线测试与 146 项隐藏合成 UI 结果；它们不是本轮真实请求的替代证据，本轮也不把旧测试描述为新重跑。
