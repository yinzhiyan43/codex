# 日常使用与当前验证边界（M3.a）

此文档整理已实现的本地纯文本工作台、可编辑多窗口与显式授权的只读文件/Git面板。M3.a 的合成验收不等于整个应用或原92项目标已经完成；真实输入法、VoiceOver、多屏和完整官方功能对照仍待验收。

## 启动

使用本 fork 的开发分支。依赖固定在 workbench/package.json / package-lock.json；需要Node.js 26、现有Electron依赖及Xcode命令行工具。只读助手构建使用本机clang与xcrun查到的系统Git；缺少工具时会构建失败，不自动安装或降级运行。不要运行来源不明的构建脚本。

```sh
cd /path/to/codex/workbench
npm run check
npm run desktop:chat
```

`desktop:chat` 构建并打开本地工作台，复用已存在的官方CLI ChatGPT登录；不会自动发送模型请求。输入后普通Enter或发送按钮先打开确认，明确确认后才请求模型。不自动安装核心、不创建凭据、不改共享Codex配置；不在本轮新增真实模型验收。该工作台当前为纯文本聊天，未提供工具执行、附件或终端；文件面板只读取用户明确选择并核对过的目录。

需要完全隔离演示时，可运行离线验收脚本，它们只创建合成数据与隐藏窗口：

```sh
npm run desktop:repository:smoke -- /absolute/private/output
npm run desktop:editable:smoke -- /absolute/private/output
npm run desktop:keyboard:smoke -- /absolute/private/output
```

## 已有能力

- 官方持久纯文本会话、确认发送、流式回应及停止；重启只读加载保存记录，不自动resume/turn或重发。
- 保存历史浏览、完整轮次服务端游标分页、刷新、取消；本地项目/未读/置顶；已核验的重命名、归档/恢复、分区与指定轮次分叉；有界完整保存文字复制。
- 官方保存用户/助手文字搜索与标题/预览搜索、归档范围、分页，结果在固定会话副窗打开。正文搜索是已固定的实验接口，不承诺实时未保存文字、SQLite-only或非交互来源及精确命中轮次定位。
- 浅色/深色/跟随系统，主副窗一致；侧栏显示/宽度/折叠、密度和字号属于工作台私有偏好。
- 菜单键盘导航、对话框焦点恢复、组合输入保护、语义状态与Chromium无障碍树部分验证。真实中文IME、原生Tab顺序、VoiceOver、多屏与完整参考对照未验收。

## 多窗口编辑规则

在会话菜单或搜索结果打开副窗口，默认只读。点击“取得编辑权”才核验持久会话并开放输入。每会话只有一个编辑窗口：若另一窗口占用，先到占用窗口“保存并释放编辑权”，再在目标窗口取得；不自动抢占或覆盖。其他窗口同步查看已确认草稿与生成状态。不同会话可独立编辑；整个工作台一次只生成一个回合，其他会话可继续保存草稿。确认只在发起窗口出现，同会话其他窗口可停止正在执行的一轮。

主窗口自己正在生成时沿用既有导航限制，需等到终态再切换主会话；其他会话副窗口仍可编辑。每次编辑提交绑定窗口、固定会话、租约与草稿版本，过期写入被拒绝。保存失败时本地文字保留，先重试保存；发生编辑权/版本冲突时先复制本地文字，再明确选择使用已保存草稿，不会静默覆盖。

正常关闭会请求所有相关编辑窗口完成保存；失败、超时或输入法尚未结束时保留窗口并提示。单独关闭生成副窗不停止核心，其运行时保留到官方终态，其他会话仍可编辑。归档、归档结果未知或临时来源保持只读。关闭并重启不自动恢复副窗拓扑，可显式重新打开同一会话。

## 发送、关闭和异常恢复

确认发送后，工作台先把本次文字与发送前轮次边界写入自己的 sessions.json；保存成功才调用发送接口。收到官方回执后，在同一原子写入中清空相应已发送草稿及未决记录，不等生成终态。保存失败时仍保留磁盘上已确认的草稿和未决记录，禁止再次发送，可用“重试持久保存”重做本地保存，再按提示重连核对执行状态。保存重试本身不会解开未知执行锁。

重启发现未决记录时，整个工作台禁发送，涉及的会话禁止继续改写草稿；其他会话仍可编辑和保存。先在主窗口重连，再点“核对上次发送结果”：它只读取同一官方持久会话的元数据与最近20个完整轮次。只有找到发送前边界之后与原文一致的保存用户消息、且未见执行中轮次，才原子清除标记；仍与发送文字一致的草稿才清空，不清除不同的新草稿。没有正向证据、边界超出本页或状态不明时，保留文字与锁定，不自动重发或把“没找到”当作“没发送”。

如果核对仍不能证明结果，请保留现有文件和草稿，查看官方保存记录；当前界面没有强制解锁/猜测重发入口。其他客户端同时发送完全相同的文字无法靠文本匹配证明回合归属，因此不要把该核对当作跨客户端幂等保证。关闭整个应用会停止工作台自己拥有的核心；下一次启动只读恢复，不自动继续生成或重发。

## 文件夹与 Git（只读）

在主窗口或固定会话副窗口展开“文件与 Git（只读）”，点击“选择并核对文件夹”。取消不会改绑定。新草稿可以显式选择或替换目录，草稿文字保留；已有会话只能选择与其官方cwd绝对路径一致的文件夹，不因选择另一个目录而改变执行目标。会话一旦绑定，路径、设备和inode都必须保持；被移动、删除或替换时会停止读取，请恢复原目录或新建会话。旧记录首次只读核验后建立cwd基线，之后远端cwd变化会阻止激活/续聊/分叉。路径规范化后与旧官方cwd字符串不同的目录也会拒绝，当前没有旧会话改cwd入口。

绑定保存在工作台自己的sessions.json；同一会话的所有窗口共享绑定，各自的文件、目录和差异展示独立。重启保留目录授权和草稿，不恢复文件内容缓存或自动扫描目录。新线程使用所选cwd；分叉核对来源cwd并继承授权。它们仍沿用纯文本、read-only、禁止网络的聊天策略，浏览的文件不会自动附到模型输入。

“读取目录”最多展示200项，不递归扫描；可点子目录/文件或输入根内相对路径查看有效UTF-8文字。单文件上限256 KiB。符号链接、特殊文件、Git内部目录及越界路径不开放；二进制、编码、权限、缺失、超大和根身份变化均有反馈。文本按原样显示，不执行HTML或代码。

“Git状态”展示索引/工作区列，点击变更分别查看已暂存和未暂存补丁，含重命名与未跟踪说明。每次进程输出上限512 KiB、最长4秒，最多4个原生读取在途，超限会终止并显示错误。仅支持根内普通.git目录；非仓库、bare、linked worktree、submodule及外部Git元数据不开放。只读Git在macOS沙箱中运行，禁止网络/普通文件写入/其他程序执行，禁外部diff、textconv、fsmonitor及hooks；隔离不可用则禁用Git，不做普通执行回退。取消、切换根或关窗会终止读取，旧响应不会进入其他会话。

这里提供本地文件夹授权和只读检查。官方project实验管理接口尚未接入，依赖SQLite状态的该服务在无状态环境下不可用；本地项目标签和此目录选择都不冒充官方项目创建、移动或删除。文件编辑、终端、行号跳转、差异定位、分支比较和全量文件搜索仍待后续阶段。

## 文件与恢复

工作台在自己的应用数据目录保存sessions.json与ui-preferences.json。官方核心保存会话正文；工作台只保存私有草稿、索引、组织、界面偏好及目录授权身份，不复制登录凭据。损坏/不安全/未来版本文件保留并禁用相关写入，不自动覆盖。草稿“已保存”以磁盘确认的版本为准；突然崩溃最多保证已确认版本，本地尚未确认的键入无法承诺恢复。

工作台只协调自己拥有的窗口和单个受控核心进程。官方协议没有跨进程CAS/多页快照；其他官方客户端并发修改、进程/网络异常与服务器未知结果仍有边界，不声称彻底解决。
