# M3.b 工具展示、一次性审批与补充输入：范围及退出条件

基线02eaee06f；沿用固定0.162.1与原92ID。本轮对应WB-030/037/038/039/041/043，交叉WB-004/025/031/036/044/086/087/088/092。只在本机开发、合成服务及新隔离仓库验证，不调用真实模型、不改共享配置/模型参数/Logo/main、不push，保留已有改动。

复用既有ThreadItem投影、请求去重和serverRequest/resolved；增加有界工具卡和明确未知类型说明。命令显示完整命令/cwd/原因，文件审批需可核对完整修改范围；不完整或无法核对禁止同意。只支持accept/decline/cancel，不支持acceptForSession、策略修订、grantRoot或持久权限授予；permissions/MCP/dynamic执行请求继续明确unsupported。工具输出与计划/推理摘要仅按实际协议显示，禁止HTML执行或任意host调用。

补充输入直接复用官方ToolRequestUserInput schema，支持有界问题、每题单选及自由文字，按官方TUI标签和user_note答案数组编码；“跳过回答”才回空answers并明确模型可能继续；“停止本轮”走精确turn/interrupt，不能把空答当取消。界面采用每题必答的产品限制，不冒称官方schema要求必填。答案仅发送给对应请求，不写sessions.json/日志/历史展示，秘密输入暂不收集，提示改由可信官方客户端处理或停止；官方核心可能保存已提交的普通答案。isBlocking明确显示，自动过期以服务端resolved/轮次终态/连接变化为准，不从autoResolutionMs假造确认。

所有答复由主进程验证sender、实际会话、轮次、连接代次、单次请求键及当前可答复窗口；观察窗口仅看状态。重复/晚到/已经resolved不能再次答复；断线保存只读状态、重连不自动重发。关窗不擅自批准，主窗口只有核对到同一轮次时才可继续处理或停止。

本轮不解除现有纯文本工具禁用配置守卫，不引入终端、任意命令输入、额外工具注册或真实执行模式；工具/审批/输入闭环以合成官方事件和假服务验收，不把此阶段描述成真实编码执行已开放。若后续需要启用官方工具或变更执行沙箱，将明确列出具体权限动作与验证边界。

退出条件：批准/拒绝/取消的准确回包与一次性、输入必填/选项/自由文字/取消/过期、断线重连/重复冲突/迟到、同异会话与多窗归属、完整范围不足禁批准、存储不含答案、文本惰性展示与有界数据均有合成断言；新增隐藏UI验收并回归既有能力，独立只读复审修复确定问题后，脱敏报告及原92目标增量更新，最终仅本地提交。
