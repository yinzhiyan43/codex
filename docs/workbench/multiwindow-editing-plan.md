# M2.m 可编辑多窗口实施与验收方案

基线：本地2f664907b，公开远端231f3aa。只本地提交、不push、不改main，不调用真实模型；官方核心、用户配置/模型/推理/速度与Logo保留。

## 归属与执行

主进程统一持有SessionStore。每个持久会话最多一个编辑租约，租约绑定确切窗口与随机代号，每次草稿提交校验会话、租约和版本；旧窗口、旧租约、旧版本不能覆盖。副窗口显式请求编辑；占用中显示保存/释放提示，不强制接管。不同会话独立编辑。主窗口切换先flush；同ID主副同步已确认草稿、生成和停止状态，确认弹窗只在发起窗口出现。

复用既有OfficialChatController，为副窗创建固定会话运行时：共享受控核心但不能启动/重连/释放核心、不能改主窗口lastId/freshDraft；所有运行时通过主进程全局执行门互斥，一个工作台一次生成一个会话，其他会话仍可编辑。未持有租约的运行时禁止写回旧草稿。未知发送结果停止连接并禁止自动重发；取消不自动释放仍在执行的请求。

关闭窗口前通过受限IPC请求renderer flush并等待保存确认；失败或组合输入未结束则保留窗口和本地文字，给出重试提示。副窗关闭不停止核心或其他会话，已执行的回合由主进程保留到结束。主关闭先收齐所有窗口的保存确认，再释放运行时/窗口/核心。崩溃只能保证已确认保存的草稿，界面区分待保存与已保存。

副窗继续固定来源、精确sender/frame/URL、受限命令、网络隔离与独立读取预算；归档/结果未知/临时会话保持只读，搜索结果可请求编辑前先核验持久ID。跨应用/进程协议无CAS，不宣称阻止官方客户端并发；发送前继续metadata状态核对，工作台单实例锁只协调自己。

## 验收

合成单元/协议测试覆盖租约争抢、版本冲突、过期异步返回、存储失败、同/不同会话编辑、同时确认一次发送、全局互斥、取消/未知结果、断线重连、关闭期间输入和恢复。后台隐藏App覆盖实际IPC绑定与窗口生命周期、主副草稿/生成同步、保存确认关闭/失败阻止关闭、重启不自动发、长历史分页、搜索来源、主题同步与键盘/IME策略。回归既有功能并独立只读复审；人工原生IME/Tab/VoiceOver与真实模型仍不冒称通过。

完成后整理启动说明、支持能力、日常使用边界、测试/未验证项与下一阶段缺口。整体完成前持续推进，不在单次局部提交后停工。

## 发送持久保护补充

发送前原子保存token、线程ID、原文与最新轮次边界；保存失败不调用turn/start。ACK后立即在同一事务清空相应已发送草稿和标记。无法确认的结果跨重启继续锁定全局发送和该会话编辑；明确只读核对最多20个完整轮次，只有边界之后原文正向匹配且无执行中轮次才解锁，缺乏证据继续保留。保存重试不能释放未知执行门；断连过渡期也必须持有inflight屏障。其他客户端相同文字的归属不具备协议级幂等保证。用户已明确授权此组本地保护与合成测试。
