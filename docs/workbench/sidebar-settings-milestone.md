## 已实现

- 侧栏分组独立展开/折叠；会话继续使用原有导航、上下文菜单和主控制器。固定底部显示设置入口与已加载会话数，列表独立滚动，长标题可查看完整 title。
- 现有搜索入口提供明确标注的“筛选已加载会话”：仅筛选当前已加载的分组名和会话标题，不请求搜索接口、不搜索正文。筛选期间临时显示匹配的折叠分组，清除筛选后恢复原折叠状态。完整服务端搜索仍待实现。
- 主窗口设置对话框包含“界面与侧栏”“连接与能力”“关于”三页；侧栏隐藏时仍可从标题栏进入。原生 modal 管理焦点与 Escape，返回时聚焦入口；分组保存期间保留键盘焦点。
- 可用设置只有侧栏显示、宽度（220/259/300px）、列表密度（舒适/紧凑）、主窗口阅读字号（13/14/16px）与全部展开。改动持久保存、成功后生效，失败显示错误并恢复上次保存值。
- “连接与能力”只有实际能力说明，不提供模型/推理/速度、账户、安全权限、MCP、钩子、浏览器或 Claude Code 的假控件。原聊天模型选择入口及其 guard 不变；设置不调用它。

进入设置先经过原 `flushDraft()`，保留尚在 180ms 防抖中的草稿；不切聊天路由、不替换待发送内容。普通侧栏偏好只更新展示，不进入核心命令。原官方核心适配、分页/刷新、会话持久化、项目/分区、分叉、复制及只读副窗口均保留。

## 独立偏好与边界

`UiPreferencesStore` 使用主进程固定的工作台数据目录下 `ui-preferences.json`，与 `sessions.json` 分开。真实聊天沿用工作台自有 profile；离线 UI 测试使用临时独立根。不接收 renderer 文件路径，不读取或写入共享 Codex TOML、认证文件或官方桌面状态。

偏好协议只有固定键及枚举；折叠键最多 512 个，受限长度/字符并拒绝重复；版本/大小/文件类型校验失败保留原文件，不自动覆盖或降级。更新经过单队列合并，私有临时文件 0600、fsync 后原子 rename，失败不推进内存状态；拒绝叶文件和直属目录符号链接。关闭主窗口移除偏好 IPC 并等待已接受的写队列。

偏好 read/update 只存在主窗 preload，通过现有精确 owner、mainFrame、index URL 检查与 IpcBudget。副窗使用独立 preload，没有偏好入口；没有原始 IPC、任意 RPC、config 对象、文件/进程能力。

项目/分区分组 ID 从 `[本地项目名, 官方分区ID]` 的 SHA-256 前 24 hex 生成，避免原 `group-N` 因排序、置顶、归档漂移。分区改名不变键；本地项目目前只有名称无独立 ID，整体改名后该组的折叠状态重新展开，旧键只作为受限偏好保留。恢复旧项目名时可恢复其原折叠值；最多 512 个键，设置“全部展开”可清除。
