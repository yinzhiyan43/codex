# M3.c1 本地变更审阅快照与隔离计划

日期2026-10-17，基线90c62a59f，开发分支workbench/desktop-stable-0.162.1。本轮交付本地差异审阅与不可执行的隔离工作区计划，未开放生产worktree生命周期、核心模型审查或真实编码执行。见[范围与退出条件](change-review-plan.md)、[机器证据](change-review-results.json)、[日常说明](daily-use.md)。仅本地提交，不push，原92项目标与ID保留。

## 当前可用

在已有根授权下，主窗和固定副窗各自选择Git变更，区分HEAD→索引、索引→当前工作文件。显示固定HEAD、读取时间、旧/新行号；切换审阅范围保留选择。二进制说明不伪造行号；combined/不支持的hunk明确不能完整编号。未跟踪文字不是Git补丁，其中的@@不会伪装成行号。未展开的未跟踪目录不能取得“已核对”快照，须从文件树查看具体文件。尚无提交时仍可审阅暂存文字，但不生成基于HEAD的计划。

“重新核对快照”以重复的状态原始指纹、HEAD和选定文件的两组补丁比对发现变化。变化后保留标明过期的旧内容、撤销计划，旧review句柄不能因字节后来恢复而复活；必须刷新Git状态重选。此校验只覆盖所选审阅内容和有界Git状态，不对其他文件内容提供审查证明，不是持续监控或文件系统原子快照。显示“本次核对未发现变化”而非“修改已安全”。当前文件按钮由host从已捕获Git条目取路径，不采纳补丁header中的路径；文件预览显示行号并注明当前版本，不能把暂存补丁行号直接定位为当前行号。

计划重新核对同一审阅版本后，显示会话、授权根、固定提交、随机建议目录名和detached模式。目标父目录尚未选择，计划只在本窗口内存保存，executionEnabled恒false。明确不会复制暂存/未暂存/未跟踪/忽略内容；worktree共享Git对象及部分元数据，不是安全沙箱。既有会话cwd、目录授权、草稿和执行权限不随计划改变。重启不保存快照、补丁或计划，也不创建或清理目录。

## 实现边界

只扩展固定只读Git助手的HEAD元数据查询，沿用macOS无网络/写入/其他程序执行的沙箱、固定Git及外部diff/textconv/hooks/fsmonitor禁用。没有放宽沙箱，没有任意Git argv、shell或终端接口。renderer仅发送当前scope和opaque review ID；host核真实owner、session key、完整根身份和查询序列。取消使审阅过期并停止后续顺序读取；切换/关闭令迟到结果失效。每个助手4秒/512KiB、全局4在途、原目录200项/文本256KiB限制保持；每个审阅范围最多渲染2000行并明确截断，截断内容不假称完整。

产品没有worktree add/remove、force/prune/reset/clean或分支删除入口。实际Git创建清理只写在测试模块中，不导入desktop、host、renderer或构建入口。测试基于本轮全新可丢弃仓库，从计划固定HEAD建立真正detached worktree，并核源文件/索引/main不变、未提交内容不复制、目标不覆盖、锁定拒绝、取消不清理、hooks不执行。

实际试验确认：Git普通worktree remove也可能删除忽略文件。测试清理必须先用含--ignored=matching和--untracked-files=all的状态检查拒绝任何脏内容，再普通remove；覆盖tracked/untracked/ignored三类。这个顺序preflight和remove之间仍有竞态，不能当成生产安全删除或可恢复归档证明。夹具的最终递归删除仅清理任务自己生成的整个可丢弃根，不作为产品归档策略。生产操作还需独立的受限写代理、目标/所有权持久记录、显式确认、链接/环境/竞态边界、可恢复快照及恢复设计；linked-worktree Git读取仍按M3.a拒绝。此处是未实施范围，没有已拒绝、待审批或结果未知的生产操作。
